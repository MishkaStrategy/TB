# Переключение приватного режима из Telegram

Администратор может менять режим доступа без редактирования `.env` и без
перезапуска процесса.

## Использование

1. Откройте чат с ботом под Telegram ID из `ADMIN_TELEGRAM_IDS`.
2. Отправьте `/admin`.
3. Нажмите кнопку `🔐 Доступ: приватный` или `🌐 Доступ: публичный`.
4. Бот сразу применит противоположный режим и обновит подпись кнопки.

В публичном режиме защищённые команды доступны всем Telegram-пользователям. В
приватном режиме они доступны только ID из `ALLOWED_TELEGRAM_IDS` и
пользователям, которым доступ был разрешён через persistent access registry.
Сама админ-панель по-прежнему проверяет `ADMIN_TELEGRAM_IDS`.

## Хранение настройки

`PUBLIC_ACCESS_ENABLED` остаётся безопасным начальным значением и используется,
пока администратор не сохранил выбор в панели. После первого переключения режим
хранится в `data/runtime_settings.json`.

На VDS каталог `data` является ссылкой на `/var/lib/fvg-alert-bot`, поэтому
выбранный режим переживает перезапуск службы, обновление релиза и rollback.
Удаление `runtime_settings.json` возвращает поведение к значению
`PUBLIC_ACCESS_ENABLED` из `/etc/fvg-alert-bot.env`.

## Проверка

```bash
PUBLIC_ACCESS_ENABLED=true \
MPLCONFIGDIR=/tmp/trading-assistant-mpl \
  .venv/bin/python -m unittest discover -s tests -v
```

После обновления VDS откройте `/admin`, переключите режим и проверьте доступ к
`/menu` из тестового Telegram-аккаунта, который отсутствует в allowlist.
