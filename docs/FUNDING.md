# Фандинг Bitunix

## Где открыть

После запуска release candidate `1.0.0-rc7` funding доступен двумя способами:

- команда `/funding` в системном меню Telegram слева;
- кнопка `💸 Фандинг` внутри `/menu`.

Экран показывает топ-50 положительных и топ-50 отрицательных текущих ставок
Bitunix. На каждой странице отображается до 10 инструментов в каждую сторону,
а также изменение последней цены за 24 часа.

Кнопки экрана:

- `◀️` и `▶️` — переключение страниц;
- `🔄 Обновить` — повторная загрузка данных Bitunix;
- `⬅️ Главное меню` — возврат в панель бота.

## Как трактуется ставка

Live-ответ `GET /api/v1/futures/market/funding_rate/batch` содержит
`fundingRate` уже в процентных пунктах. Дополнительно умножать его на 100 нельзя.

Примеры:

- `1.514051` отображается как `+1.5141%`;
- `-1.514051` отображается как `−1.5141%`;
- ошибочный вариант `−151.4051%` больше не формируется.

Для рейтинга используются публичные методы, не требующие API-ключа:

```text
GET /api/v1/futures/market/funding_rate/batch
GET /api/v1/futures/market/tickers
```

`funding_rate/batch` является единственным источником ставки, знака, интервала и
времени расчёта. Из `tickers` копируются только `open`, `lastPrice` и `last` для
вычисления изменения цены за 24 часа. Поля ticker не могут заменить batch-ставку.

Если загрузка тикеров временно недоступна, ставки всё равно отображаются, а
изменение цены за 24 часа показывается как `н/д`.

## Проверка после обновления VDS

```bash
cat /opt/fvg-alert-bot/VERSION
systemctl is-active fvg-alert-bot
journalctl -u fvg-alert-bot -n 100 --no-pager
```

Затем отправьте новую команду `/funding` или нажмите
`/menu → 💸 Фандинг → 🔄 Обновить`. Системный список команд Telegram обновляется
при старте бота через `setMyCommands`.
